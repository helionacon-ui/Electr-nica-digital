# Electrónica Digital · Guía para aprobar

Guía de estudio interactiva de Electrónica Digital (UPCT, Grado en Ingeniería Biomédica, 3.º).

Última actualización: 8 de noviembre de 2026.

Ábrela en: https://helionacon-ui.github.io/Electr-nica-digital/

Está dividida en páginas: portada, el examen y cómo estudiar, una página por bloque de temas, prácticas con simulador, exámenes resueltos paso a paso, hojas de problemas, demostraciones, autoevaluación, simulacros, formulario, glosario y plan de estudio. `guia-completa.html` es la misma guía en una sola página. Se puede instalar como aplicación y funciona sin conexión después de abrirla una vez.

## Código

- `scripts/vhdl/`: código VHDL de las prácticas.
- `scripts/python/`: modelos en Python que reproducen cada práctica y sus salidas (`scripts/salidas/`).
- `fuente/`: fuentes de la guía y herramientas para reconstruirla (`python3 fuente/tools/build.py --site`).
