Práctica 1 · Introducción al diseño con herramientas CAD/EDA

Crear un proyecto en Xilinx ISE, describir un circuito y probarlo en la placa Basys.

💡 Cómo se evalúa

Las prácticas pesan el 20 %. Se evalúan con memorias e informes y, y, según se decida en el curso, con pruebas prácticas. Hay que defender el trabajo: explicar cómo funciona cada diseño y por qué tomaste cada decisión. Es obligatorio asistir (mínimo 80 %) y sacar al menos un 4,0 en teoría y en prácticas para aprobar. Si usas IA para generar código (permitido en la Práctica 4), tienes que entenderlo, revisarlo y justificarlo.

Simulador de las prácticas

Elige una función, cambia los valores y mira el código VHDL equivalente, la salida tipo consola y el cronograma. Los botones «Abrir en el simulador» de cada práctica cargan aquí el ejemplo correspondiente.

Objetivo

Aprender el flujo completo con una función trivial: describir, simular, sintetizar, asignar pines y programar la placa.

Pasos

Práctica 1

Crear el proyecto y describir el circuito

Crea un proyecto en Xilinx Foundation/ISE para la FPGA de la placa Basys y describe un circuito que enlace interruptores con LEDs.

🧭 Antes de empezar: qué piden y qué teoría usas

Herramientas: entorno ISE, captura de esquemáticos, diagramas de estados y VHDL (los tres modos de entrada de diseño). Ya conoces entity/architecture del Tema 13.

1 Nuevo proyecto

En ISE: File → New Project. Elige el nombre, la familia de la FPGA y el dispositivo que indica la placa Basys (consulta el manual de tu placa). Indica lenguaje VHDL y simulador ISim.

2 Nueva fuente

Project → New Source → VHDL Module. Pega el código de abajo (o dibuja el esquemático equivalente con puertas AND, OR, XOR).

3 Comprueba la sintaxis

Haz doble clic en Check Syntax. Debe terminar sin errores.

✅ Resultado final

Un módulo p1_leds con 8 interruptores, 4 pulsadores y 8 LEDs, listo para simular.

vhdl · p1_leds.vhd
-- Práctica 1: entradas y salidas de la placa Basys.
-- Cada interruptor enciende el LED de su mismo número.
library ieee;
use ieee.std_logic_1164.all;

entity p1_leds is
  port (
    sw  : in  std_logic_vector(7 downto 0);   -- interruptores
    btn : in  std_logic_vector(3 downto 0);   -- pulsadores
    led : out std_logic_vector(7 downto 0)    -- LEDs
  );
end p1_leds;

architecture flujo of p1_leds is
begin
  -- Los 4 LEDs bajos copian los interruptores; los 4 altos muestran un AND y un OR de ejemplo.
  led(3 downto 0) <= sw(3 downto 0);
  led(4) <= sw(0) and sw(1);          -- AND
  led(5) <= sw(0) or  sw(1);          -- OR
  led(6) <= sw(0) xor sw(1);          -- XOR
  led(7) <= btn(0);                   -- el pulsador 0 enciende el LED 7
end flujo;

Práctica 2

Sumador de 4 bits

✔ verificado

Describe un sumador de 4 bits con acarreo de entrada y salida. Muestra la suma en 4 LEDs y el acarreo en un quinto.

🧭 Antes de empezar: qué piden y qué teoría usas

Teoría: sumador completo y en cascada (T5); aritmética con unsigned (T13).

1 Qué se pide

Entradas a, b (4 bits) y cin; salidas s (4 bits) y cout.

2 Idea

Para no perder el acarreo, se hace la suma en 5 bits: se amplían a y b con un '0' por la izquierda. El bit más significativo es cout.

3 Código

Ver abajo.

✅ Resultado final

s=(a+b+cin)mod16 y cout=⌊(a+b+cin)/16⌋. Comprobado con las 512 combinaciones del modelo.

vhdl · p2_sum4.vhd
-- Práctica 2: sumador de 4 bits con acarreo de entrada y de salida.
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity p2_sum4 is
  port (
    a, b : in  std_logic_vector(3 downto 0);
    cin  : in  std_logic;
    s    : out std_logic_vector(3 downto 0);
    cout : out std_logic
  );
end p2_sum4;

architecture rtl of p2_sum4 is
  signal t : unsigned(4 downto 0);        -- un bit más para el acarreo
begin
  t    <= ('0' & unsigned(a)) + ('0' & unsigned(b)) + ("0000" & cin);
  s    <= std_logic_vector(t(3 downto 0));
  cout <= t(4);
end rtl;

Práctica 2

Comparador y multiplexor

✔ verificado

Diseña un comparador de 4 bits con salidas A>B, A=B, A<B y un multiplexor 4:1.

🧭 Antes de empezar: qué piden y qué teoría usas

Teoría: comparador y multiplexor (T5); when ... else y with ... select (T13).

1 Comparador

Con unsigned el comparador es una línea por salida. Exactamente una de las tres salidas vale 1: es una buena comprobación.

2 Multiplexor

Un with sel select enumera las cuatro posibilidades de sel; la última usa others para cubrir los valores no binarios de std_logic.

✅ Resultado final

Comparador: una y solo una salida a 1. Mux: y=dsel​.

vhdl · p2_cmp4.vhd
-- Práctica 2: comparador de 4 bits.
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity p2_cmp4 is
  port (
    a, b       : in  std_logic_vector(3 downto 0);
    gt, eq, lt : out std_logic
  );
end p2_cmp4;

architecture rtl of p2_cmp4 is
begin
  gt <= '1' when unsigned(a) >  unsigned(b) else '0';
  eq <= '1' when unsigned(a) =  unsigned(b) else '0';
  lt <= '1' when unsigned(a) <  unsigned(b) else '0';
end rtl;

Práctica 2

Display de 7 segmentos

Muestra en un display de 7 segmentos de la Basys una cifra BCD recibida por los interruptores.

🧭 Antes de empezar: qué piden y qué teoría usas

Teoría: decodificador BCD a 7 segmentos con indiferentes en 1010–1111 (T5); en la Basys los segmentos son activos a nivel bajo.

1 Tabla

Para cada cifra, qué segmentos (a a g) deben encenderse. En lógica positiva el 8 enciende los siete; en la Basys hay que invertir.

2 Código

Un with d select con las 10 cifras, y "1111111" (apagado) para el resto.

3 Activa un dígito

La Basys tiene 4 dígitos con ánodo común: para ver una cifra hay que activar el ánodo de ese dígito (a nivel bajo).

✅ Resultado final

Con d=0111 el display muestra un 7: segmentos a, b, c a 0 (encendidos), el resto a 1.

vhdl · p2_seg7.vhd
-- Práctica 2: decodificador BCD a 7 segmentos para la Basys (segmentos activos a nivel bajo).
-- seg = (a, b, c, d, e, f, g). Un 0 enciende el segmento.
library ieee;
use ieee.std_logic_1164.all;

entity p2_seg7 is
  port (
    d   : in  std_logic_vector(3 downto 0);
    seg : out std_logic_vector(6 downto 0)
  );
end p2_seg7;

architecture rtl of p2_seg7 is
begin
  with d select
    seg <= "0000001" when "0000",  -- 0
           "1001111" when "0001",  -- 1
           "0010010" when "0010",  -- 2
           "0000110" when "0011",  -- 3
           "1001100" when "0100",  -- 4
           "0100100" when "0101",  -- 5
           "0100000" when "0110",  -- 6
           "0001111" when "0111",  -- 7
           "0000000" when "1000",  -- 8
           "0000100" when "1001",  -- 9
           "1111111" when others;  -- apagado (1010 a 1111 no son BCD)
end rtl;

Práctica 3

Contador módulo N

✔ verificado

Diseña un contador síncrono de módulo N configurable, con reset asíncrono, habilitación y una salida de fin de cuenta.

🧭 Antes de empezar: qué piden y qué teoría usas

Teoría: contador de módulo N, biestables ⌈log2​N⌉ (T8); proceso síncrono con reset asíncrono (T13).

1 Estructura

Un único proceso con clk y rst en la lista de sensibilidad. El reset va antes que el flanco.

2 Módulo N

Si cnt = N-1 vuelve a 0; si no, incrementa. El generic N hace el diseño reutilizable.

3 Fin de cuenta

fin vale 1 cuando cnt = N-1: sirve para encadenar contadores.

✅ Resultado final

Secuencia 0,1,…,N−1,0,…. Para N=10: 4 biestables.

vhdl · p3_contador.vhd
-- Práctica 3: contador síncrono de módulo N con reset asíncrono y habilitación.
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity p3_contador is
  generic ( N : positive := 10 );
  port (
    clk, rst, en : in  std_logic;
    q            : out std_logic_vector(3 downto 0);
    fin          : out std_logic                       -- vale 1 en el último estado
  );
end p3_contador;

architecture rtl of p3_contador is
  signal cnt : unsigned(3 downto 0) := (others => '0');
begin
  process (clk, rst)
  begin
    if rst = '1' then
      cnt <= (others => '0');
    elsif rising_edge(clk) then
      if en = '1' then
        if cnt = N - 1 then
          cnt <= (others => '0');
        else
          cnt <= cnt + 1;
        end if;
      end if;
    end if;
  end process;

  q   <= std_logic_vector(cnt);
  fin <= '1' when cnt = N - 1 else '0';
end rtl;

Práctica 3

Divisor de frecuencia

✔ verificado

Genera una señal de 1 Hz a partir del reloj de 50 MHz de la placa y úsala para hacer parpadear un LED.

🧭 Antes de empezar: qué piden y qué teoría usas

Teoría: contador como divisor (T8); DIV=fin​/fout​.

1 Cálculo

DIV=50000000. La salida conmuta cada DIV/2=25000000 ciclos: se cuenta de 0 a 24999999 (25 bits).

2 Código

Contador con comparación y una señal s que se invierte al llegar al final.

3 Prueba

En simulación no esperes 25 millones de ciclos: baja DIV (por ejemplo, a 10) en el test bench y comprueba la forma de onda.

✅ Resultado final

LED parpadeando a 1 Hz (medio segundo encendido y medio apagado).

vhdl · p3_divisor.vhd
-- Práctica 3: divisor de frecuencia. Con reloj de 50 MHz y DIV = 50_000_000 da una salida de 1 Hz.
library ieee;
use ieee.std_logic_1164.all;

entity p3_divisor is
  generic ( DIV : positive := 50_000_000 );     -- relación f_in / f_out (número par)
  port (
    clk, rst : in  std_logic;
    clk_out  : out std_logic
  );
end p3_divisor;

architecture rtl of p3_divisor is
  signal cnt : integer range 0 to DIV/2 - 1 := 0;
  signal s   : std_logic := '0';
begin
  process (clk, rst)
  begin
    if rst = '1' then
      cnt <= 0; s <= '0';
    elsif rising_edge(clk) then
      if cnt = DIV/2 - 1 then
        cnt <= 0;
        s   <= not s;                           -- conmuta cada medio periodo
      else
        cnt <= cnt + 1;
      end if;
    end if;
  end process;
  clk_out <= s;
end rtl;

Práctica 3

Antirrebote de un pulsador

✔ verificado

Un pulsador mecánico rebota unos milisegundos. Diseña un circuito que entregue un nivel limpio.

🧭 Antes de empezar: qué piden y qué teoría usas

Teoría: sincronizar la entrada con 2 biestables para evitar la metaestabilidad (T6) y aceptarla solo si permanece estable un tiempo (T10).

1 Sincroniza

s1 y s2 son dos biestables D en serie: la entrada asíncrona se alinea con el reloj.

2 Cuenta de estabilidad

Si la entrada cambia, reinicia el contador. Si llega a LIM sin cambiar, acepta el valor.

3 Calcula LIM

20 ms a 50 MHz son 106 ciclos: contador de 20 bits.

✅ Resultado final

Un solo pulso limpio por pulsación, aunque la señal original rebote.

vhdl · p3_antirrebote.vhd
-- Práctica 3: antirrebote. La salida sigue a la entrada solo si esta permanece estable LIM ciclos.
-- Con reloj de 50 MHz y LIM = 1_000_000 el filtro espera 20 ms.
library ieee;
use ieee.std_logic_1164.all;

entity p3_antirrebote is
  generic ( LIM : positive := 1_000_000 );
  port (
    clk, btn : in  std_logic;
    limpio   : out std_logic
  );
end p3_antirrebote;

architecture rtl of p3_antirrebote is
  signal s1, s2 : std_logic := '0';           -- sincronizador de dos biestables
  signal prev   : std_logic := '0';
  signal cnt    : integer range 0 to LIM := 0;
  signal sal    : std_logic := '0';
begin
  process (clk)
  begin
    if rising_edge(clk) then
      s1 <= btn;  s2 <= s1;                   -- evita la metaestabilidad
      if s2 /= prev then                      -- la entrada ha cambiado: reinicia la cuenta
        prev <= s2;
        cnt  <= 0;
      elsif cnt = LIM then
        sal  <= prev;                         -- estable el tiempo suficiente: se acepta
      else
        cnt  <= cnt + 1;
      end if;
    end if;
  end process;
  limpio <= sal;
end rtl;

Práctica 3

Máquina de estados: detector de secuencia

✔ verificado

Implementa en VHDL el detector Mealy de la secuencia 101 del Tema 10.

🧭 Antes de empezar: qué piden y qué teoría usas

Teoría: diagrama de estados de Mealy y su traducción a dos procesos.

1 Tipo enumerado

type estado_t is (S0, S1, S2); deja que la herramienta elija la codificación.

2 Dos procesos

El primero guarda el estado en el flanco. El segundo, combinacional, calcula sig y z con un case.

3 Evita latches

Asigna z <= '0' al principio del proceso combinacional: así z se asigna en todos los casos.

✅ Resultado final

Para x=1,0,1,0,1,1,0,1 da z=0,0,1,0,1,0,0,1.

vhdl · p3_detector101.vhd
-- Práctica 3: máquina de estados. Detector Mealy de la secuencia 101 con solape.
library ieee;
use ieee.std_logic_1164.all;

entity p3_detector101 is
  port (
    clk, rst, x : in  std_logic;
    z           : out std_logic
  );
end p3_detector101;

architecture rtl of p3_detector101 is
  type estado_t is (S0, S1, S2);
  signal est, sig : estado_t := S0;
begin
  -- Proceso 1: registro de estado (parte secuencial)
  process (clk, rst)
  begin
    if rst = '1' then
      est <= S0;
    elsif rising_edge(clk) then
      est <= sig;
    end if;
  end process;

  -- Proceso 2: lógica de siguiente estado y de salida (parte combinacional)
  process (est, x)
  begin
    z <= '0';
    case est is
      when S0 =>
        if x = '1' then sig <= S1; else sig <= S0; end if;
      when S1 =>
        if x = '0' then sig <= S2; else sig <= S1; end if;
      when S2 =>
        if x = '1' then sig <= S1; z <= '1'; else sig <= S0; end if;
    end case;
  end process;
end rtl;

Práctica 4 · Desarrollo de sistemas digitales mediante VHDL

⚠️ Sobre el uso de IA

Se permite usar IA como apoyo, pero el código debe ser comprendido, revisado y justificado por ti. En la defensa pueden pedirte que expliques una línea, que encuentres un error o que lo modifiques. La forma segura de prepararte: pide el código, simúlalo, tradúcelo a un diagrama y busca los fallos típicos (latches, reset, reloj dividido, señales no asignadas).

Objetivo

Construir un sistema completo combinando bloques: el ejemplo de la guía muestra cuatro cifras en el display multiplexado de la Basys.

Práctica 4

Display de 4 dígitos multiplexado

✔ verificado

Muestra cuatro cifras BCD en el display de 4 dígitos de la Basys. Calcula la frecuencia de refresco.

🧭 Antes de empezar: qué piden y qué teoría usas

Teoría: multiplexación en el tiempo, contador de refresco, decodificador de 7 segmentos activo a nivel bajo, múltiples dígitos con ánodo común.

1 Idea

Los 4 dígitos comparten los 7 segmentos. Solo uno está activo cada vez. Se alternan tan rápido que el ojo los ve todos encendidos.

2 Contador de refresco

Un contador libre de 18 bits. Sus dos bits altos eligen el dígito: cada dígito dura 216 ciclos.

3 Selección

Un with sel select elige la cifra y activa el ánodo correspondiente (activo a 0).

4 Frecuencias

Cambio de dígito: 50MHz/216=762,9 Hz. Refresco de cada dígito: 762,9/4=190,7 Hz.

✅ Resultado final

Cuatro cifras estables, sin parpadeo visible, con refresco de 190,7 Hz por dígito.

vhdl · p4_display4.vhd
-- Práctica 4: manejo multiplexado de un display de 4 dígitos (Basys). Muestra 4 cifras BCD.
-- Se enciende un dígito cada vez. Con reloj de 50 MHz se cambia de dígito a 762,9 Hz (50e6/2^16)
-- y cada dígito se refresca a 190,7 Hz: el ojo los ve todos encendidos y sin parpadeo.
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity p4_display4 is
  port (
    clk    : in  std_logic;                        -- 50 MHz
    d3, d2, d1, d0 : in std_logic_vector(3 downto 0);
    seg    : out std_logic_vector(6 downto 0);     -- activos a nivel bajo
    an     : out std_logic_vector(3 downto 0)      -- ánodos, activos a nivel bajo
  );
end p4_display4;

architecture rtl of p4_display4 is
  signal cnt : unsigned(17 downto 0) := (others => '0');   -- 2^16 ciclos por dígito
  signal sel : std_logic_vector(1 downto 0);
  signal dig : std_logic_vector(3 downto 0);
begin
  process (clk)
  begin
    if rising_edge(clk) then cnt <= cnt + 1; end if;
  end process;
  sel <= std_logic_vector(cnt(17 downto 16));

  with sel select dig <= d0 when "00", d1 when "01", d2 when "10", d3 when others;
  with sel select an  <= "1110" when "00", "1101" when "01", "1011" when "10", "0111" when others;

  with dig select
    seg <= "0000001" when "0000", "1001111" when "0001", "0010010" when "0010",
           "0000110" when "0011", "1001100" when "0100", "0100100" when "0101",
           "0100000" when "0110", "0001111" when "0111", "0000000" when "1000",
           "0000100" when "1001", "1111111" when others;
end rtl;

Ejemplo: alarma de temperatura con histéresis

Un sensor da la temperatura en décimas de grado. Se quiere una alarma de alta (≥37,5 ∘C) y una de baja (<36,0 ∘C). Sin histéresis, una medida que oscile alrededor del umbral haría parpadear la alarma. Con histéresis, la alarma se desactiva solo cuando la medida baja del umbral menos un margen (0,5 °C).

Prácticas 5-7

Alarma con histéresis

Diseña un módulo p6_alarma que reciba temp (10 bits, décimas de grado) y active al_alta si T≥375 y al_baja si T<360, con histéresis de 5 décimas.

🧭 Antes de empezar: qué piden y qué teoría usas

Teoría: comparadores (T5), biestable que recuerda el estado de la alarma (T6), proceso síncrono (T13).

1 Qué hay que recordar

La alarma depende del pasado (si ya estaba activa o no) y no solo de la entrada: es un circuito secuencial con un biestable por alarma.

2 Reglas

Alta: se activa con T≥TALTA​ y se desactiva con T<TALTA​−H. Baja: se activa con T<TBAJA​ y se desactiva con T≥TBAJA​+H. Entre ambos valores mantiene el estado.

3 Código

Ver abajo.

4 Casos límite que hay que probar

T=374 (no activa), 375 (activa), 373 (sigue activa por la histéresis), 369 (se desactiva), y los equivalentes para la baja.

✅ Resultado final

Para las medidas 365,370,374,375,376,373,371,369,… la alarma de alta se activa en 375 y se desactiva en 369.

vhdl · p6_alarma_incubadora.vhd
-- Prácticas 5 a 7 (ejemplo de módulo): alarma de temperatura con histéresis para un sistema de monitorización.
-- Entrada: temperatura en décimas de grado (0 a 1023). Salidas: alarma de alta y de baja.
-- La histéresis evita que la alarma parpadee cuando la medida oscila alrededor del umbral.
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity p6_alarma is
  generic (
    T_ALTA  : natural := 375;    -- 37,5 °C: se activa la alarma de alta
    T_BAJA  : natural := 360;    -- 36,0 °C: se activa la alarma de baja
    HIST    : natural := 5       -- 0,5 °C de histéresis
  );
  port (
    clk, rst : in  std_logic;
    temp     : in  std_logic_vector(9 downto 0);
    al_alta  : out std_logic;
    al_baja  : out std_logic
  );
end p6_alarma;

architecture rtl of p6_alarma is
  signal t : unsigned(9 downto 0);
  signal a, b : std_logic := '0';
begin
  t <= unsigned(temp);
  process (clk, rst)
  begin
    if rst = '1' then
      a <= '0'; b <= '0';
    elsif rising_edge(clk) then
      if    t >= T_ALTA        then a <= '1';
      elsif t <  T_ALTA - HIST then a <= '0';
      end if;
      if    t <  T_BAJA        then b <= '1';
      elsif t >= T_BAJA + HIST then b <= '0';
      end if;
    end if;
  end process;
  al_alta <= a;
  al_baja <= b;
end rtl;
